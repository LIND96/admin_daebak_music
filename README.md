# admin_daebak_music

Web application (Next.js + Gin) with JWT auth, PostgreSQL, and shadcn/ui.

## Structure

- `backend/` — Go (Gin) API
- `frontend/` — Next.js (shadcn/ui)
- `doc/` — Documentation (Indonesian)
- `docker-compose.yml` — Docker orchestration
